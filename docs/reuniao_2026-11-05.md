## Experimento sugerido pela professora: estimativa com poucos dados

Pedido relatado por Pedro: investigar se há um caminho de predição/projeção
para SKUs cuja base seja insuficiente. A viabilidade ainda não está demonstrada.

- Definir primeiro o alvo: preço de referência para uma data com pouca
  cobertura ou previsão para uma data futura. São avaliações diferentes.
- Investigar recuperação de observações reais e comparáveis adequados antes
  de usar estimativas para preencher a necessidade de análise.
- Comparar com referência simples, como mediana de comparáveis da mesma data
  ou último preço disponível, conforme o alvo. Registrar seleção dos atributos,
  conjunto de avaliação, MAE em R$ e resultado por SKU/grupo.
- Para projeção futura, treinar apenas com datas anteriores e avaliar em
  datas posteriores. Para baixa cobertura na mesma data, ocultar observações
  conhecidas para avaliação, sem usar o próprio preço-alvo nas variáveis.
- Mostrar a quantidade de dados, a defasagem e o erro medido. Caso não haja
  evidência suficiente, indicar indisponibilidade da estimativa.
- Preservar preços estimados em saída separada com método, data e versão.
  Não contá-los como registros observados nem misturá-los silenciosamente
  à mediana ou dispersão observadas. A interface identificará cada origem.
